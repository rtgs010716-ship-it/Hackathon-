# AgriTamil AI – விவசாயியின் AI நண்பன்

Tamil-first agricultural guidance prototype for farmers. Includes voice and text questions, simulated crop-image analysis, crop knowledge, and locally stored history.

## Run locally

```sh
npm install
npm run dev
```

## Project notes

- Built with TanStack Start, React, TypeScript, Tailwind CSS, and shadcn/ui.
- The AI assistant and crop disease results are demo responses; no live model or diagnostic service is configured.
- Conversation and history are stored in the browser.
- Browser speech recognition and Tamil text-to-speech are used when available.
- The GitHub copy uses editable SVG artwork for the hero and sample crop images.

AI crop results are for initial guidance only. Farmers should confirm diagnoses and treatments with an agricultural expert.
